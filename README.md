# Отмаз Pro · генератор отмазок для начальника

Вариант В из [BRIEF.md](BRIEF.md): пародия на премиальный ИИ-стартап. Нейросеть «ОТМАЗ-4 Turbo» рассуждает, пишет отмазку потоком и оценивает её правдоподобие.

## Запуск

Двойной клик по `index.html`. Сборка и сервер не нужны. Шрифты Manrope и JetBrains Mono грузятся из Google Fonts; без интернета сайт откроется со системными шрифтами.

Только десктоп, ширина от 1280 px. Всё ключевое держится в центральной колонке шириной 9/16 от высоты экрана, поэтому вертикальный кроп под Reels работает без доработок.

## Путь в кадре

1. **Главная** — живой WebGL-шар реагирует на курсор (клик по нему даёт всплеск), CTA «Попробовать Pro».
2. **Оплата** — бутафорская: тестовая карта •••• 4242, ничего не вводится и не отправляется. «Оплатить лицом» запускает сканирование: рамка, сетка точек, пульс, галочка.
3. **Генератор** — ситуацию можно ввести вручную или выбрать чип или пункт истории, тогда текст «впечатается» сам. Дальше идут шаги рассуждения и потоковый ответ, кольцо правдоподобия и уровень драмы. Кнопки «Драматичнее / Короче / Другая» действительно переписывают ответ: шесть уровней, от «Телеграфа» до «Трагедии в трёх актах».
4. **«Отправить начальнику»** открывает макет мессенджера: сообщение уходит, начальник печатает и отвечает. Это концовка ролика.

## Режиссёрские клавиши

Работают, когда курсор не стоит в поле ввода (`Esc` убирает фокус из поля).

| Клавиша | Действие |
|---|---|
| `R` | Сброс на главную |
| `1` / `2` / `3` | Главная / Оплата / Генератор |
| `4` | Мессенджер с текущей отмазкой (или с демо-отмазкой) |
| `D` | Демо: генератор сам впечатает случайную ситуацию |
| `M` | Звук вкл/выкл (кнопка также в правом нижнем углу) |

Звук синтезируется через Web Audio и по умолчанию включён. Переключатель «Пишу от лица: он / она» в боковой панели меняет род во всех текстах.

## Устройство

- `js/data.js` — база: 5 ситуаций по 16 отмазок, фразы для уровней драмы, ответы начальника.
- `js/engine.js` — распознавание ситуации и сборка текста нужного уровня драмы.
- `js/orb.js` — шейдер шара и пружинная физика его перелётов между экранами.
- `js/audio.js` — звуки.
- `js/app.js` — экраны, генератор, мессенджер, горячие клавиши.

Анимируются только transform и opacity, переходы построены на настоящих пружинах (CSS `linear()`). На Intel UHD при 1920×1080 держится около 60 fps. `prefers-reduced-motion` учтён.
